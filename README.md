# Attention-Gated Fusion for Modality-Robust Affective Computing

Attention-gated fusion conditioned on a missingness mask, trained with modality dropout, evaluated against early/late/fixed-weight fusion, dropout-only fusion, gating-only-no-dropout, and a post-2023 imputation-style baseline — on CMU-MOSI.

## Reproducing results

1. Open `notebooks/attention_gated_fusion.ipynb` in Google Colab.
2. `Runtime → Change runtime type → T4 GPU` (training is CPU-feasible but ~15-20x slower; see notebook Phase 3 for timing notes).
3. Run all cells top to bottom. The **only manual step** is in the data-download cell:
   - Get the file id for `MOSI/aligned_50.pkl` from the [Self-MM feature release](https://drive.google.com/drive/folders/1E5kojBirtd5VbfHsFp6FYWkQunk73Nsv) (right-click the file → Get link → copy the id from the URL).
   - Paste it into `FILE_ID = "PASTE_FILE_ID_HERE"`.
   - If `gdown` hits a quota/permission error (common on this heavily-shared file), use the `drive.mount()` fallback commented in the same cell with your own copy of the file.
4. The full experiment grid (7 models × 3 seeds × 4 missingness rates) takes roughly 20–45 minutes on a T4 GPU. Per-run timing and ETA print as it goes.
5. All tables in `manuscript.md` §3 (Results) are generated directly from `results_raw.csv` and `config_log.json`, both written by the notebook — rerunning should reproduce them (modulo minor floating-point/hardware variation).
